Does one round of self-review make an AI answer research questions better?

Not on average. A reviewer model fixes wrong “Unanswerable” answers, but it also rewrites good answers into worse ones, and the two cancel out.

Each line is a 95% interval for the change, from a paired bootstrap over the same questions. Every interval crosses zero. The shaded band is the gap between two near-identical setups: differences inside it are noise.

Where the change comes from

The total change splits into three kinds of revision. Fixing a wrong “Unanswerable” adds; rewording an answer that was already given mostly subtracts. Bars add up to each setup's total change (the dark tick).

How it works

  1. Retrieve. BM25 picks paragraphs from the paper: 20 for Sonnet 5.5, 5 for Haiku 5.5 (the weak writer).
  2. Answer. The writer answers in JSON with a short answer and the paragraph IDs it used.
  3. Check. Free code checks flag long answers and citation problems.
  4. Critique. A critic reads the same paragraphs and the draft, and lists problems from a fixed checklist.
  5. Revise once. The writer fixes flagged drafts; everything else keeps its first answer.

Caveats: answer-F1 rewards word overlap, so a correct answer worded differently can score low; the revise prompt was adjusted after a 20-question pilot drawn from the same questions; one revise round, one dataset, two models.
